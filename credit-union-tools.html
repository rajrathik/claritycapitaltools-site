Credit Union Utilities

A growing collection of practical open-source tools for credit union technology, data and operations teams. Source code is published so institutions can review, adapt and run these utilities within their own environments.

What these will be

Small, single-purpose utilities addressing ordinary problems that come up in credit union technology, data and operations work — the kind of thing a team might otherwise build from scratch each time. Published openly so they can be inspected, modified and run internally rather than adopted as a service.

Each utility will be documented here in plain terms, with the code and installation detail kept on GitHub.

Independence and review. These are independently published open-source utilities. They are not a product of, sponsored by, or endorsed by any credit union or employer. Organizations should independently review security, privacy, regulatory, operational and technology requirements before using any utility in a production environment.
